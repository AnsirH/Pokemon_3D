# 플레이어 이동 시스템 요구사항 명세서 (구현 완료)

## 개요
플레이어 캐릭터의 이동, 애니메이션, 충돌 처리, 지면 감지 시스템을 담당하는 핵심 시스템입니다. 3D 포켓몬스터 게임의 기본적인 탐험 기능을 제공하며, 다른 모든 시스템의 기반이 됩니다.

### 주요 목표 ✅
- ✅ 8방향 부드러운 이동 구현
- ✅ 직관적인 입력 처리 (WASD, 방향키)
- ✅ 정확한 충돌 감지 및 이동 제한
- ✅ 이동 상태에 따른 애니메이션 연동
- ✅ 지면 타입별 발소리 및 이벤트 처리

### 관련 시스템과의 연관성
- **풀숲 시스템**: 이동을 통한 SurfaceChecker를 통한 지면 감지
- **NPC 시스템**: 이동을 통한 NPC 접촉 (미구현)
- **배틀 시스템**: 이동 중 조우 시 배틀 전환 (미구현)
- **UI 시스템**: 이동 상태 표시 (HUD) (미구현)

## 구현된 요구사항 목록

### ✅ REQ-001: 8방향 이동 (완료)
- **설명**: 플레이어가 8방향(상, 하, 좌, 우, 대각선 4방향)으로 이동 가능
- **입력**: 
  - WASD 키 (W: 위, A: 왼쪽, S: 아래, D: 오른쪽)
  - 방향키 (↑, ←, ↓, →)
  - Unity Input System 사용
- **출력**: 
  - 플레이어 캐릭터의 8방향 이동
  - 이동 방향에 따른 애니메이션 전환
- **구현**: `PlayerMovement.cs`에서 CharacterController 기반 이동 처리
- **수락 기준**: ✅ 모든 방향으로 정확히 이동, 부드러운 애니메이션 전환, 충돌 시 즉시 이동 중단

### ✅ REQ-002: 속도 전환 (완료)
- **설명**: Shift 키를 통한 걷기/달리기 속도 전환
- **입력**: 
  - Shift 키 (이동 중 누름/뗌)
  - Unity Input System의 OnRun 콜백 사용
- **출력**: 
  - 걷기 속도: PlayerData.WalkSpeed (기본값: 5.0 units/sec)
  - 달리기 속도: PlayerData.RunSpeed (기본값: 10.0 units/sec)
  - 부드러운 가속/감속 처리
- **애니메이션**: 
  - 걷기: Walk 애니메이션
  - 달리기: Run 애니메이션
- **구현**: `PlayerMovement.cs`에서 부드러운 속도 전환 처리
- **수락 기준**: ✅ Shift 키 입력에 즉시 반응, 속도 전환 시 애니메이션 동기화, 부드러운 가속/감속 처리

### ✅ REQ-003: 충돌 처리 (완료)
- **설명**: 지형, 건물, 나무 등과의 충돌 시 이동 제한
- **입력**: 
  - 충돌 감지 이벤트 (Physics.OverlapSphere)
  - 충돌 오브젝트의 Collider 정보
- **출력**: 
  - 이동 방향 차단
  - 충돌 지점에서 이동 중단
- **충돌 오브젝트 타입**: 
  - 지형 (Terrain)
  - 건물 (Building)
  - 나무 (Tree)
  - 기타 장애물 (Obstacle)
- **구현 방식**: CharacterController + Physics.OverlapSphere 사용
- **구현**: `PlayerMovement.cs`의 `CanMove()` 메서드에서 충돌 체크
- **수락 기준**: ✅ 모든 충돌 오브젝트에서 정확히 멈춤, 충돌 후 정상적인 이동 재개, 벽 통과 버그 없음

### ✅ REQ-004: 지면 감지 시스템 (완료)
- **설명**: 플레이어가 밟고 있는 지면 타입 감지 및 이벤트 처리
- **기능**: 
  - 지면 타입별 발소리 재생
  - 지면별 특수 이벤트 실행 (풀숲 조우 등)
  - 여러 지면이 겹칠 때 우선순위 처리
- **입력**: 
  - 플레이어 위치
  - 지면 Collider 정보
- **출력**: 
  - 지면 타입 정보
  - 발소리 재생
  - 지면 이벤트 실행
- **구현**: `SurfaceChecker.cs`에서 구체 오버랩으로 지면 감지
- **수락 기준**: ✅ 정확한 지면 감지, 우선순위 처리, 이벤트 실행

## 구현된 상세 설계

### 클래스 구조

#### PlayerController (메인 컨트롤러) ✅
- **파일**: `PlayerController.cs`
- **역할**: 플레이어의 모든 컴포넌트를 통합 관리하는 중앙 컨트롤러
- **주요 기능**: 하위 컴포넌트들 초기화 및 연결, 입력 → 이동 → 애니메이션 파이프라인 관리, 지면 이벤트 처리

#### PlayerInputHandler (입력 처리) ✅
- **파일**: `PlayerInputHandler.cs`
- **역할**: Unity Input System을 사용한 입력 처리
- **주요 기능**: WASD/조이스틱 입력 처리, Shift 키 달리기 입력, 입력 데드존 적용, 입력 정규화 처리

#### PlayerMovement (이동 로직) ✅
- **파일**: `PlayerMovement.cs`
- **역할**: CharacterController 기반 3D 이동 구현
- **주요 기능**: 걷기/달리기 속도 전환, 부드러운 가속/감속 처리, 충돌 감지 및 이동 제한, 스텝 이벤트 발생, 플레이어 회전 처리

#### PlayerAnimationController (애니메이션 제어) ✅
- **파일**: `PlayerAnimationController.cs`
- **역할**: Animator를 통한 플레이어 애니메이션 관리
- **주요 기능**: 8방향 이동 애니메이션 지원, 걷기/달리기 상태 전환, 부드러운 애니메이션 블렌딩, 발걸음 이벤트 발생

#### SurfaceChecker (지면 감지) ✅
- **파일**: `SurfaceChecker.cs`
- **역할**: 플레이어가 밟고 있는 지면 타입 감지
- **주요 기능**: 구체 오버랩으로 지면 감지, 여러 지면이 겹칠 때 우선순위 처리, 디버그용 기즈모 표시

### 데이터 구조

#### PlayerData (플레이어 데이터) ✅
- **파일**: `PlayerData.cs`
- **역할**: 플레이어의 이동 관련 설정값 관리
- **데이터**: 회전 속도, 걷기/달리기 속도, 가속/감속 값
- **특징**: Unity Inspector에서 쉽게 조정 가능한 ScriptableObject

### 이벤트 흐름

#### 이동 처리 플로우 ✅
1. **입력 감지**: `PlayerInputHandler`가 WASD/방향키 입력 감지
2. **입력 전달**: `PlayerController`에 입력 벡터 전달
3. **충돌 체크**: `PlayerMovement`의 `CanMove()` 메서드로 충돌 체크
4. **이동 실행**: `CharacterController`로 실제 이동
5. **애니메이션**: `PlayerAnimationController`에 이동 상태 전달
6. **지면 감지**: `SurfaceChecker`가 지면 타입 감지
7. **이벤트 실행**: 발소리 재생 및 지면 이벤트 실행

#### 속도 전환 플로우 ✅
1. **Shift 키 감지**: `PlayerInputHandler`가 Shift 키 상태 감지
2. **상태 변경**: `PlayerController`의 `isRunning` 상태 변경
3. **속도 계산**: 걷기/달리기 속도에 따른 `currentSpeed` 계산
4. **애니메이션**: `PlayerAnimationController`에 걷기/달리기 애니메이션 전환
5. **이동 적용**: 새로운 속도로 이동 처리
