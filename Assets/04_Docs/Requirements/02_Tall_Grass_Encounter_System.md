# 풀숲 조우 시스템 요구사항 명세서 (구현 완료)

## 개요
플레이어가 풀숲 영역에 진입할 때 야생 포켓몬과의 조우를 처리하는 시스템입니다. 전통적인 포켓몬스터 게임의 핵심 메커니즘으로, 탐험의 재미와 긴장감을 제공합니다.

### 주요 목표 ✅
- ✅ 풀숲 진입 감지 및 시각적 피드백
- ✅ 확률 기반 야생 포켓몬 조우 시스템
- ✅ 조우 시 배틀 씬으로의 자연스러운 전환 (기본 틀만 존재)
- ✅ 다양한 풀숲 타입별 조우 확률 차별화
- ✅ 몰입감 있는 풀 흔들림 애니메이션

### 관련 시스템과의 연관성
- **플레이어 이동 시스템**: SurfaceChecker를 통한 풀숲 진입 감지
- **배틀 시스템**: 조우 시 배틀 전환 (미구현)
- **데이터 관리 시스템**: WildOccurrenceData를 통한 포켓몬 데이터 참조
- **UI 시스템**: 조우 알림 및 전환 효과 (미구현)

## 구현된 요구사항 목록

### ✅ REQ-005: 풀숲 영역 설정 (완료)
- **설명**: 플레이어가 감지할 수 있는 풀숲 영역 시스템 구현
- **입력**: 
  - 플레이어 위치 (Transform)
  - 풀숲 영역 Collider (Trigger)
  - 플레이어 이동 상태
- **출력**: 
  - 풀숲 영역 정보 전달
  - 시각적 효과 트리거
- **구현**: 
  - `TallGrassSurface`가 `WildOccurrenceSurface`를 상속
  - `SurfaceChecker`를 통한 지면 감지
  - 플레이어 발걸음 이벤트 시 지면 이벤트 실행
- **수락 기준**: ✅ 풀숲 진입 시 정확히 감지, 플레이어 진입 후 발을 내딛을 시 즉시 시각적 효과 재생

### ✅ REQ-006: 조우 확률 계산 (완료)
- **설명**: 풀숲 진입 시 야생 포켓몬과의 조우 확률 계산
- **입력**: 
  - 풀숲 영역 타입 (WildOccurrenceData)
- **출력**: 
  - 조우 성공/실패 여부
  - 조우된 포켓몬 정보 (디버그 로그)
  - 조우 확률 수치
- **확률 공식**: 
  ```
  랜덤 값 (0-100) <= 포켓몬별 조우 확률
  ```
- **구현**: `WildOccurrenceSurface.ReturnWildPokemon()` 메서드에서 확률 계산
- **수락 기준**: ✅ 설정된 확률대로 조우 발생, 확률 계산이 정확함, 조우 실패 시 자연스러운 필드 복귀

### ⚠️ REQ-007: 배틀 씬 전환 (기본 틀만 존재)
- **설명**: 조우 성공 시 배틀 씬으로 전환
- **입력**: 
  - 조우 성공 이벤트
  - 조우된 포켓몬 데이터
  - 플레이어 파티 정보
- **출력**: 
  - 배틀 씬 로드 (미구현)
  - 배틀 데이터 전달 (미구현)
  - 전환 애니메이션 (미구현)
- **현재 상태**: `BattleSystem.cs`에 기본 틀만 존재
- **수락 기준**: ⚠️ 조우 시 즉시 배틀 전환 (미구현), 전환 중 버그 없음 (미구현), 전환 실패 시 안전한 복귀 (미구현)

## 구현된 상세 설계

### 클래스 구조

#### SurfaceBase (기본 지면 클래스) ✅
- **파일**: `SurfaceBase.cs`
- **역할**: 모든 지면 타입의 기본 클래스
- **주요 기능**: 지면 타입 열거형 정의, 지면별 발소리 관리, 지면 이벤트 실행 인터페이스

#### TallGrass (풀숲 시각적 효과) ✅
- **파일**: `TallGrass.cs`
- **역할**: 풀숲의 시각적 상호작용 처리
- **주요 기능**: 플레이어 이동 방향에 따른 풀 흔들림 애니메이션, 풀숲 이동 사운드 재생, 랜덤 애니메이션 속도로 자연스러운 효과

#### TallGrassSurface (풀숲 지면) ✅
- **파일**: `TallGrassSurface.cs`
- **역할**: 풀숲 지면의 이벤트 처리
- **주요 기능**: WildOccurrenceSurface를 상속받아 야생 포켓몬 조우 기능 포함, 풀숲 내 모든 TallGrass 컴포넌트와 상호작용, 플레이어 이동 시 관련 풀숲들에 시각적 효과 적용

#### WildOccurrenceSurface (야생 포켓몬 조우) ✅
- **파일**: `WildOccurrenceSurface.cs`
- **역할**: 야생 포켓몬 조우 확률 계산 및 처리
- **주요 기능**: ScriptableObject 기반 확률 데이터 참조, 랜덤 확률 계산으로 야생 포켓몬 조우 결정, 확률 기반 포켓몬 선택 시스템

#### SurfaceChecker (지면 감지) ✅
- **파일**: `SurfaceChecker.cs`
- **역할**: 플레이어가 밟고 있는 지면 타입 감지
- **주요 기능**: 구체 오버랩으로 지면 감지, 여러 지면이 겹칠 때 우선순위 처리 (WildOccurrenceSurface 우선), 디버그용 기즈모 표시

### 데이터 구조

#### WildOccurrenceData (야생 포켓몬 조우 데이터) ✅
- **파일**: `WildOccurrenceData.cs`
- **역할**: 야생 포켓몬 조우 확률 데이터 관리
- **데이터 구조**: 포켓몬 이름과 조우 확률을 구조체로 정의, ScriptableObject로 확률 테이블 관리
- **특징**: 확장 가능한 데이터 구조

#### ESurfaceType (지면 타입) ✅
- **파일**: `SurfaceBase.cs` 내부 정의
- **역할**: 지면 타입 열거형
- **타입**: Ground, TallGrass

### 이벤트 흐름

#### 조우 처리 플로우 ✅
1. **플레이어 이동**: `PlayerMovement`에서 스텝 이벤트 발생
2. **지면 감지**: `SurfaceChecker`가 현재 지면 타입 감지
3. **이벤트 실행**: `SurfaceBase.ExecuteSurfaceEvent()` 호출
4. **풀숲 상호작용**: `TallGrassSurface`에서 관련 풀숲들에 시각적 효과 적용
5. **조우 확률 계산**: `WildOccurrenceSurface.ReturnWildPokemon()`에서 확률 계산
6. **결과 처리**: 조우 성공 시 디버그 로그 출력, 실패 시 자연스러운 복귀

#### 풀숲 시각적 효과 플로우 ✅
1. **플레이어 이동**: `PlayerController`에서 이동 방향 감지
2. **풀숲 감지**: `TallGrassSurface`에서 플레이어 주변 풀숲 감지
3. **애니메이션 실행**: `TallGrass.Interact()`에서 방향별 풀 흔들림 애니메이션
4. **사운드 재생**: 풀숲 이동 사운드 재생
5. **랜덤 효과**: 각 풀숲마다 랜덤 애니메이션 속도 적용
